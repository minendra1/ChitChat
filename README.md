# 💬 ChitChat

A full-stack, real-time messaging application featuring live typing indicators, image sharing, and secure authentication.

## 🚀 Tech Stack
- **Frontend:** React, Redux Toolkit, Tailwind CSS
- **Backend:** Node.js, Express.js, Socket.io
- **Database:** MongoDB Atlas, Mongoose
- **Media Storage:** Cloudinary
- **Deployment:** Render (Frontend/Backend)

## 🌟 Features
- 1:1 Real-time messaging
- Secure User Authentication (JWT)
- Live typing indicators and online status
- Image uploads via Cloudinary
- Fully responsive mobile & desktop UI

## 🛠️ Local Development
1. Clone the repository: `git clone https://github.com/yourusername/chitchat.git`
2. Install frontend dependencies: `cd frontend && npm install`
3. Install backend dependencies: `cd ../backend && npm install`
4. Set up your `.env` files in both directories.
